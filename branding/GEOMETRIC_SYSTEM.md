## 📐 CORE ARCHITECTURAL LAWS

### 1. Spatial Viewport Split (40% / 60% Ratio)
- **Control Sidebar (40%):** Enforces a rigid 2:5 viewport ratio (`lg:w-[40%]`). Houses control triggers, status badges, and primary initiation cards.
- **Canvas / Detail Matrix (60%):** Enforces a 3:5 viewport ratio (`lg:w-[60%]`). Houses the 9-node EnneaCore canvas and deep sub-chapter logical doctrines / forms.
- **Horizontal Horizon Alignment:** The top control bar of both the 40% and 60% panels must align to the exact same vertical y-coordinate (`h-14` / `pt-1 pb-3.5 mb-6 border-b border-[#262a33]/60`).

### 2. Baseline Grid & Spacing Scale (8px System)
- **Padding:** Standard structural containers use `p-6 lg:p-8` (24px desktop 32px).
- **Gap & Spacing:** Sub-elements use 8px steps (`gap-2` = 8px, `gap-4` = 16px, `gap-6` = 24px, `gap-8` = 32px).
- **Interactive Trigger Height:** Primary CTA buttons enforce exact `h-[48px]` or `h-[54px]` heights with 1.5px letter-spacing.

### 3. EnneaCore 3x3 Matrix Symmetry
- **Node Matrix:** 9 nodes positioned in an immutable 3x3 symmetrical geometric grid:
  - Row 1: Node 01 (Federation), Node 02 (Blueprint), Node 03 (Pro)
  - Row 2: Node 04 (Mobile), Node 05 (Marketplace), Node 06 (Market)
  - Row 3: Node 07 (Analytics), Node 08 (GDPR Shield), Node 09 (Access Gateway)
- **Laser Vector Connections:** Laser beam lines rendered via SVG connecting adjacent nodes in a balanced geometric network.

### 4. Mineral Color & Border Uniformity
- **Background Obsidian:** `#090b0e` (Base viewport), `#12161A` (Primary Card), `#1A1D23` (Controls Bar).
- **Borders:** `#262a33`/60 (Structural split lines), `#00FF66`/40 (Interactive accent highlights).
