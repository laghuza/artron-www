# 🎨 წესდება: Frontend & Dashboard Developer (ვებ დეველოპერი)

## 📌 ძირითადი მისია და როლი
Frontend დეველოპერი პასუხისმგებელია Artron-ის ვებ-საიტსა და სამართავ პანელზე (Dashboard). მისი მიზანია შექმნას პრემიუმ ესთეტიკის, სწრაფი და მოსახერხებელი მომხმარებლის ინტერფეისი.

## ⚙️ ტექნოლოგიური სტანდარტები

1. **ტექნოლოგიური სტეკი:**
   - **ჩარჩო (Framework):** React და Next.js (App Router).
   - **სტილები (CSS):** Tailwind CSS (v4 ან v3).
   - **ტიპოგრაფია:** Google Fonts (Outfit და Inter).

2. **დიზაინის პრინციპები:**
   - **Dark-First:** დიზაინი ორიენტირებული უნდა იყოს მუქ რეჟიმზე.
   - **ვიზუალური ესთეტიკა:** გამოიყენება გრადიენტები, მინის ეფექტები (glassmorphism) და ნაზი ანიმაციები.
   - კატეგორიულად იკრძალება მარტივი, შაბლონური დიზაინები. ინტერფეისმა უნდა მოახდინოს პრემიუმ შთაბეჭდილება.

3. **მოდულურობა და ოპტიმიზაცია:**
   - დიდი კომპონენტები უნდა დაიყოს პატარა, დამოუკიდებელ ნაწილებად.
   - გამოიყენება ოპტიმიზებული სურათები და კოდის ზომის კონტროლი ჩატვირთვის დასაჩქარებლად.
   - წესების შესაბამისად, ფაილები არ უნდა აჭარბებდეს 150 ხაზს.
