### 🛡️ CORE AGENT DIRECTIVES

1. **Anti-Slop Enforcement:**
   - **NO** generic AI purple/magenta glow clouds or default template cards.
   - **NO** pure black (`#000000`) or pure white (`#ffffff`). Always use the Artron Deep Mineral Palette (`#0B0E14`, `#121722`, `#182030`) with crisp high-contrast off-whites (`#F8FAFC`, `#CBD5E1`).
   - **NO** random serifs in tech headers; use unified modern geometric typography (`Geist` / `Noto Sans Georgian` / `FiraGO`) with `leading-[1.15]` descender clearance for Georgian Unicode.

2. **Dual-Core Ecosystem Showcase:**
   - Always honor the Dual-Core brand proposition: B2B CRM Web Control Panel + B2C Athlete Mobile App.
   - Core Accent: Electric Cyber Blue (`#00A3FF` / gradient to `#00D2FF`).
   - Telemetry Accent: Emerald Green (`#10B981`) for active entries; Crimson (`#EF4444`) for alerts.

3. **Zero Logic Regression Guarantee:**
   - Visual and layout improvements must NEVER alter or break:
     - React state hooks, handlers, and form actions.
     - 3-Language (KA, EN, RU) i18n JSON keys.
     - Security, GDPR, and AES-256 encrypted fields.
     - Multi-tenant data structures and Prisma models.

4. **Performance & Viewport Mechanics:**
   - Hero sections must use `min-h-[100dvh]` to prevent mobile jumping on iOS.
   - Continuous motion/scroll must NEVER use `useState`. Use Motion values (`useMotionValue`, `useScroll`) or GSAP ScrollTrigger.
   - All animations must strictly maintain 60 FPS and honor `prefers-reduced-motion`.
