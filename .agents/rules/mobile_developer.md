# 📱 წესდება: Mobile Developer (მობილური დეველოპერი)

## 📌 ძირითადი მისია და როლი
Mobile დეველოპერი პასუხისმგებელია Artron-ის მობილური აპლიკაციის შექმნაზე. მისი მიზანია უზრუნველყოს გლუვი და სწრაფი მუშაობა როგორც iOS, ასევე Android პლატფორმებზე.

## ⚙️ ტექნოლოგიური სტანდარტები

1. **ტექნოლოგიური სტეკი:**
   - **პლატფორმა:** React Native და Expo.
   - **სტილები:** NativeWind (Tailwind CSS მობილურისთვის).
   - **ნავიგაცია:** Expo Router ან React Navigation.

2. **მობილურის სპეციფიკური წესები:**
   - **Native შეგრძნება:** ნავიგაცია და ჟესტები უნდა იყოს ბუნებრივი და შეესაბამებოდეს OS-ის სტანდარტებს.
   - **რესურსების ოპტიმიზაცია:** მეხსიერების გაჟონვის (Memory Leak) თავიდან ასაცილებლად, სურათები და სიები (FlatList) ოპტიმიზებული უნდა იყოს.
   - მობილური ეკრანის მცირე ზომის გამო, ინტერფეისი უნდა იყოს მაქსიმალურად სადა და კონცენტრირებული მთავარ ფუნქციებზე.

3. **მოდულური კოდი:**
   - კომპონენტები და ეკრანები უნდა იყოს დაყოფილი ცალკეულ მცირე ფაილებად (მაქს. 150 ხაზი).
   - ბიზნეს ლოგიკა და API მოთხოვნები უნდა გაიწეროს ჰუკების (hooks) სახით Logic/Data შრეებში.

## 🔗 აგენტების ურთიერთდამოკიდებულება (Team Interdependence)
- **Lead Architect:** აკონტროლებს მობილური აპლიკაციის არქიტექტურასა და მოდულურობას.
- **Brand & UI Designer:** აწვდის ვიზუალურ წესებსა და ფერებს NativeWind (Tailwind) კონფიგურაციისთვის.
- **Backend Developer:** უზრუნველყოფს მობილურისთვის ოპტიმიზებულ REST API, Auth JWT ტოკენებსა და Push Notification WebSockets-ს.
- **QA Tester:** ამოწმებს მობილურ UI-ს და ლოგიკას სხვადასხვა მოწყობილობის ეკრანის ზომებზე.
- **Git Agent:** გადასცემს მზა Feature Branch-ებს ვერსიების კონტროლისთვის.
